# BAM v0.5 — каталог оригинальных ресурсов и локальный визуальный слой

## Что реально реализовано

- Массовый проход по файлам .ANI в DATA без модификации источников.
- Показ первой декодируемой рамки каждой .ANI, отбор по номеру, многорамочности и статусу.
- HTML-каталог без сервера и библиотек; HTML и PNG создаются только в .local/.
- JSON-отчёт о пропущенных форматах, а не фантазийные картинки при неизвестном сжатии.
- Привязка выбранных ресурсов к ролям Battle Lab (существа + сооружения).
- Повторное нажатие переключает локальные спрайты и прежнюю процедурную графику.
- Если JS-набор, PNG или конкретная роль недоступны, игра продолжает работать со старыми рисунками.
- Кадры анимации проигрываются по времени симуляции. Пауза игры останавливает их.
- Ключевые CelHeader originX/originY сохраняются и используются как точка привязки спрайта.

В Git нет экспортированных оригинальных изображений или звуков. Изучение прав до
публичного распространения обязательно.

## С чего начать (PowerShell, корень BAM)

Один раз получить ветку v0.5 после существующей v0.4:

    git fetch origin feature/bam-v05-visuals
    git switch -c feature/bam-v05-visuals FETCH_HEAD

Если локальная ветка v0.5 уже создана, используйте git switch feature/bam-v05-visuals
вместо повторного git switch -c.

### Быстрый запуск одной командой (Windows)

    powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\preview_bam_originals.ps1 -Catalog

Команда создаст каталог превью, извлечёт 1000.ANI, назначит его
демонстрационным налётчиком и откроет игру. В игре затем нажмите
«Подключить локальные спрайты». Параметры: `-ResourceId 1000`,
`-Role raider`, `-PaletteId 100`; `-Catalog` включает полный поиск.

### 1. Сделать поиск по исходной графике

    python tools/bam_assets.py catalog DATA --palette DATA/100.PAL --output .local/bam-assets/catalog
    start .local/bam-assets/catalog/catalog.html

Скрипт сканирует файлы .ANI и пишет:
- .local/bam-assets/catalog/catalog.html — галерея с поиском;
- .local/bam-assets/catalog/catalog.json — отчёт с причинами пропусков;
- .local/bam-assets/catalog/thumbs/<ID>.png — первые кадры известных ANI.

`100.PAL` здесь используется как **кандидатная** палитра для просмотра.
Не гарантируется, что она правильная для всех ресурсов. Измените --palette
на другую .PAL и сформируйте каталог повторно, если цвета выглядят неверно.

Параметр `--limit 30` полезен для первого быстрого запуска; для полного
каталога его можно не указывать.

### 2. Экспортировать выбранную анимацию

Первый проверенный пример — оригинальный персонаж из 1000.ANI
(4 узнаваемых кадра на кандидатной палитре 100.PAL):

    python tools/bam_assets.py extract DATA/1000.ANI --palette DATA/100.PAL --output .local/bam-assets/1000

В .local/bam-assets/1000 появятся кадры frame-000.png ... frame-003.png
и metadata.json с координатами центра/опорной точки кадра.

Для любого другого ID замените 1000 на найденный номер. Если ресурс сжат,
инструмент напечатает Unsupported compression и не будет угадывать структуру.

### 3. Привязать выбранный ресурс к роли

    python tools/bam_assets.py bind --assets .local/bam-assets --game battle-lab --output .local/bam-assets/asset-pack.js --map raider=1000

Это **демонстрационная замена** в Battle Lab, не историческая идентификация
персонажа: роль исходного 1000.ANI в старой игре пока не установлена.

Для нескольких ролей сначала экспортируйте их .ANI по отдельности, затем
соберите один pack:

    python tools/bam_assets.py bind --assets .local/bam-assets --game battle-lab --output .local/bam-assets/asset-pack.js --map golem=1000 --map raider=1000

Другие роли: guardian, hunter, channeler, soldier, brute, boss,
forge, barracks, altar. Это лишь визуальные назначения; игровая симуляция
при смене рисунка не меняется. Управление скоростью анимации:
`--fps 8` (1..24) и числом загружаемых кадров:
`--max-frames 16`NaN
